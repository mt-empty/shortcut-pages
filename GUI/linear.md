# Linear

> Source: https://linear.app/keyboard-shortcuts

> Aliases: linear-app

$ Navigation
    `?                             {{Open keyboard shortcuts help}} 
    `Ctrl+K                        {{Open command palette}} 
    `G I                           {{Go to Inbox}} 
    `G C                           {{Go to Cycles}} 
    `S                             {{Search issues}} 

$ Issue Actions
    `N                             {{Create a new issue}} 
    `J / K                         {{Move between issues}} 
    `Space                         {{Open selected issue}} 
    `Esc                           {{Close modal or overlay}}
