# ClickUp

> Source: https://help.clickup.com/hc/en-us/articles/360002061214-Keyboard-Shortcuts

> Aliases: clickup-app

$ General
    `Ctrl+Shift+K                  {{Open keyboard shortcuts panel}} 
    `Ctrl+N                        {{Create a new task}} 
    `Ctrl+S                        {{Save changes}} 
    `Ctrl+F                        {{Search workspace}} 

$ Task Actions
    `Ctrl+Enter                    {{Save task or modal}} 
    `Ctrl+D                        {{Duplicate selected task or item}} 
    `Ctrl+G                        {{Open task grouping / filter options}}
