# Figma

> Source: https://help.figma.com/hc/en-us/articles/360040328653-Use-Figma-products-with-a-keyboard

$ Shortcuts Panel
    `Mac: Control Shift ?          {{Open the keyboard shortcuts panel}} 
    `Windows: Ctrl Shift ?         {{Open the keyboard shortcuts panel}} 
    `F6 (Mac) / Ctrl F6 (Windows)  {{Focus the toolbar so you can select tools with arrow keys}} 

$ Canvas Navigation
    `Shift + Arrow keys            {{Increase pan distance when moving around the canvas}} 
    `Mac: Command + or -           {{Zoom in or out}} 
    `Windows: Ctrl + or -          {{Zoom in or out}} 

$ Keyboard Selection
    `Mac: Command Space            {{Activate the keyboard box selection tool}} 
    `Windows: Ctrl Space           {{Activate the keyboard box selection tool}} 
    `Return / Enter                {{Select an object when using keyboard box selection}} 

$ View Controls
    `Shift + Arrow keys            {{Resize the keyboard selection box}} 
    `Tab / Shift Tab               {{Move between child layers in the selection cursor}}
